# PRD: K-pop 음악방송 알림 슬랙봇

## 소개/개요

K-pop 팬들이 매일 여러 음악방송 유튜브 채널을 일일이 확인해야 하는 번거로움을 해결하기 위한 슬랙봇입니다. 사용자가 관심있는 아이돌 그룹을 등록하면, 매일 정해진 시간에 해당 그룹의 새로운 음악방송 영상을 자동으로 찾아서 알림을 보내줍니다.

**해결하는 문제**: 팬들이 좋아하는 아이돌 그룹의 최신 음악방송 무대를 놓치지 않기 위해 매일 여러 유튜브 채널을 확인해야 하는 불편함

**목표**: 아이돌 팬들이 원하는 시간에 자동으로 정리된 최신 음악방송 영상 정보를 받아볼 수 있도록 하여 편의성을 제공

## 목표

1. **편의성 향상**: 매일 수동으로 여러 채널을 확인하는 시간을 90% 단축
2. **놓침 방지**: 좋아하는 그룹의 새로운 음악방송 영상을 100% 놓치지 않도록 보장
3. **개인화**: 각 사용자별로 다른 그룹과 알림 시간 설정 가능
4. **효율성**: 유튜브 API 호출 최소화를 통한 안정적인 서비스 운영

## 사용자 스토리

### 핵심 사용자 스토리
- **아이브 팬으로서**, 매일 오전 9시에 뮤직뱅크/인기가요/엠넷에 올라온 아이브의 신규 영상을 놓치지 않고 보고 싶어요.
- **뉴진스 팬으로서**, 출근 전 시간에 뉴진스의 최신 음악방송 무대를 확인하고 싶어요.
- **다양한 그룹 팬으로서**, 최대 10개 그룹을 등록하여 한 번에 여러 그룹의 소식을 받고 싶어요.

### 관리 관련 사용자 스토리
- **사용자로서**, 현재 내가 알림받고 있는 그룹 목록을 확인하고 싶어요.
- **사용자로서**, 특정 그룹의 알림을 취소하거나 전체 알림을 중단하고 싶어요.
- **사용자로서**, 알림 받는 시간을 변경하고 싶어요.

## 기능 요구 사항

### 1. 그룹 등록 및 알림 설정
1.1. 슬랙 명령어로 아이돌 그룹명(한글/영문)과 알림 시간 설정 가능
1.2. 사용자별 최대 10개 그룹까지 등록 가능
1.3. 알림 시간은 사용자별로 개별 설정 가능

### 2. 알림 관리
2.1. 현재 등록된 그룹 목록 조회 기능
2.2. 특정 그룹 알림 취소 기능
2.3. 전체 알림 취소 기능
2.4. 알림 시간 변경 기능

### 3. 영상 검색 및 알림 발송
3.1. 5개 주요 음악방송 채널에서 영상 검색 (뮤직뱅크, 인기가요, 엠카운트다운, 음악중심, 쇼챔피언)
3.2. 조회 시점 기준 1일 이내 업로드된 영상만 대상
3.3. 그룹별로 별도 메시지로 알림 발송
3.4. 메시지 내용: 제목, 링크, 옵션으로 썸네일

### 4. 데이터 관리
4.1. 사용자별 설정 정보 DB 저장
4.2. 영상 정보 캐싱을 통한 API 호출 최소화
4.3. 중복 알림 방지를 위한 발송 이력 관리

### 5. 관리자 기능
5.1. 음악방송 채널 추가/삭제 기능

### 6. 사용자 도움말
6.1. `/kpop-help` 명령어로 모든 기능과 사용법 안내
6.2. 각 명령어별 상세 설명 제공
6.3. 신규 사용자를 위한 간략한 온보딩 가이드

## 비목표 (범위 외)

1. **뮤직비디오나 기타 콘텐츠**: 음악방송 무대 영상만 대상으로 함
2. **해외 음악방송**: 한국 주요 음악방송만 지원
3. **그룹 채널 알림**: 개인 DM 알림만 지원, 단체 채널 알림은 제외
4. **동명 아티스트 구분**: 동명의 다른 그룹이나 솔로 가수 구분 기능 제외
5. **실시간 알림**: 정해진 시간에만 알림 발송 (실시간 모니터링 제외)
6. **영상 분석**: 영상 내용 분석이나 추천 기능 제외
7. **추가 검색 키워드**: 한글/영문 그룹명 외 별도 키워드 관리 제외
8. **주간 요약 알림**: 매일 알림만 지원, 주간/월간 요약 기능 제외
9. **관리자 대시보드**: 별도 모니터링 시스템이나 관리자 대시보드 제외
10. **데이터 보존 정책**: 사용자 탈퇴 시 데이터 삭제 등 개인정보 관리 정책 제외

## 기술 고려 사항

### API 제약사항
- 유튜브 API 1일 최대 100회 호출 제한
- 캐싱 시스템을 통한 API 호출 최소화 필요
- DB 저장을 통한 중복 조회 방지

### 확장성
- 예상 동시 사용자: 100명
- 슬랙 워크스페이스별 봇 설치 방식
- 수평 확장 가능한 아키텍처 고려

### 장애 대응
- 유튜브 API 장애 시 해당 채널 제외하고 서비스 계속 제공
- 음악방송 채널 비공개 전환 시 자동 제외 처리

## 성공 지표

### 기능 성능 지표
1. **알림 정확도**: 새로운 영상의 95% 이상을 놓치지 않고 알림 발송
2. **응답 시간**: 설정된 알림 시간 기준 ±5분 이내 메시지 발송
3. **API 효율성**: 일일 API 호출량 100회 이내 유지

### 사용자 만족도 지표
1. **사용자 retention**: 월간 활성 사용자 80% 이상 유지
2. **기능 사용률**: 등록된 사용자의 90% 이상이 주 3회 이상 알림 수신
3. **오류율**: 알림 발송 실패율 5% 이하 유지

## 디자인 고려 사항

### 메시지 형태
```
🎵 [그룹명] 새로운 음악방송 영상이 업로드되었습니다!

📺 뮤직뱅크 - [제목]
🔗 링크: [YouTube URL]
🖼️ [썸네일] (옵션)

📺 인기가요 - [제목]  
🔗 링크: [YouTube URL]
```

### 명령어 구조
- `/kpop-add [그룹명] [시간]` - 그룹 추가 및 알림 시간 설정
- `/kpop-list` - 현재 등록된 그룹 목록 조회
- `/kpop-remove [그룹명]` - 특정 그룹 삭제
- `/kpop-remove-all` - 전체 알림 취소
- `/kpop-time [시간]` - 알림 시간 변경
- `/kpop-help` - 모든 명령어 사용법 및 기능 안내
